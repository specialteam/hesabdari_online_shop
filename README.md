# حسابدار شاپ (Hesabdar Shop)

اپ اندروید حسابداری برای کسب‌وکارهای خرید و فروش و **واسطه‌گری** — کاملاً فارسی، راست‌به‌چپ و با تقویم **شمسی**.
ساخته‌شده با Kotlin + Jetpack Compose (Material 3) + Room.

## امکانات

- ثبت **قیمت خرید** و **قیمت فروش** هر کالا (تعداد، واحد، هزینه‌های جانبی، تاریخ شمسی، خریدار و فروشنده)
- محاسبهٔ خودکار **مبلغ سود یا زیان** هر معامله و **درصد سود/زیان**
- **بیلان کلی**: مبلغ کل خرید و فروش، اضافه/کسری، سود خالص، درصد سود، معاملات سودده و زیان‌ده، «احتمال ضرر» بر اساس سابقه، موجودی فروش‌نرفته، نمودار سود و زیان ماهانه
- **واسطه‌گری** (برچسب جداگانه): کالا مستقیم از فروشنده به خریدار می‌رسد؛ ما فقط پول را می‌گیریم و پس از تحویل، سود خود را برمی‌داریم و باقی را به فروشنده می‌دهیم. وضعیت هر مرحله (دریافت پول ← تحویل ← تسویه) ثبت می‌شود و «پول امانی نزد ما»، «قابل پرداخت به فروشندگان»، «سود قابل برداشت» و «طلب از خریداران» نمایش داده می‌شود
- **برچسب** دلخواه برای دسته‌بندی معاملات
- **فیلتر و جستجو** در حالت‌های مختلف: نوع، نتیجه (سودده/زیان‌ده/فروش‌نرفته)، مرحلهٔ واسطه‌گری، برچسب، بازهٔ تاریخ (امروز/هفته/ماه/سال/دلخواه)، مرتب‌سازی
- **فاکتور غیررسمی** (تکی یا چندکالایی، با سربرگ فروشگاه، تخفیف و مبلغ به حروف)
- **خروجی متن و PDF و چاپ** برای هر صفحه (خانه، فهرست معاملات، بیلان، جزئیات معامله، فاکتور)
- **پشتیبان‌گیری**: خروجی و ورود کل اطلاعات (JSON) از بخش تنظیمات
- تقویم شمسی، ارقام فارسی، فونت وزیرمتن، حالت روشن/تیره

## ساخت و انتشار (GitHub Actions)

| گردش‌کار | چه زمانی | خروجی |
| --- | --- | --- |
| `Build` | هر push / PR | تست‌ها + APK دیباگ (در Artifacts) |
| `Release` | push تگ `v*` یا اجرای دستی | APK امضاشده در **Releases** |

برای انتشار نسخهٔ جدید:

```bash
git tag v1.0.0 && git push origin v1.0.0
```

یا از تب **Actions ← Release ← Run workflow** نسخه را وارد کنید.

### امضای APK

پیش‌فرض، APK با کلید `keystore/release.jks` امضا می‌شود تا همهٔ نسخه‌ها روی هم نصب شوند و اطلاعات پاک نشود.
این کلید برای نصب مستقیم (sideload) است و **در مخزن عمومی است**؛ اگر اپ را در مارکت منتشر می‌کنید کلید اختصاصی خودتان را بسازید و در Secrets مخزن بگذارید:
`KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.
