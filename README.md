[![Build](https://github.com/specialteam/hesabdari_online_shop/actions/workflows/build.yml/badge.svg)](https://github.com/specialteam/hesabdari_online_shop/actions/workflows/build.yml)

حسابدار شاپ یک برنامهٔ اندروید برای ثبت و حسابداری معاملات خرید و فروش و واسطه‌گری است. رابط کاربری فارسی و راست‌به‌چپ است و تاریخ‌ها بر اساس تقویم شمسی ثبت و نمایش داده می‌شوند.

## قابلیت‌ها

### ثبت معاملات
- ثبت نام کالا، مقدار و واحد، قیمت خرید و قیمت فروش (به ازای هر واحد)، هزینه‌های جانبی، تاریخ، خریدار و فروشنده
- محاسبهٔ خودکار مبلغ و درصد سود یا زیان هر معامله
- ثبت معامله بدون قیمت فروش (فروش‌نرفته) و تکمیل آن پس از فروش
- برچسب‌گذاری معاملات برای دسته‌بندی

### واسطه‌گری
در این نوع معامله، کالا مستقیماً از فروشنده به خریدار تحویل می‌شود و تنها وجه آن نزد فروشگاه قرار می‌گیرد. پس از رسیدن کالا به خریدار، سود فروشگاه کسر و مابقی به فروشنده پرداخت می‌شود.
- پیگیری مراحل دریافت وجه از خریدار، تحویل کالا و تسویه با فروشنده
- نمایش وجه امانی نزد فروشگاه، مبلغ قابل پرداخت به فروشندگان، سود قابل برداشت و مطالبات از خریداران

### گزارش‌گیری
- بیلان شامل مجموع خرید و فروش، اختلاف قیمت، سود خالص، درصد سود، سهم معاملات سودده و زیان‌ده و موجودی فروش‌نرفته
- تفکیک نتایج بر اساس نوع معامله و برچسب، و نمودار سود و زیان ماهانه
- جست‌وجو و فیلتر بر اساس نوع، نتیجه، مرحلهٔ واسطه‌گری، برچسب و بازهٔ تاریخ، به‌همراه مرتب‌سازی

### خروجی و پشتیبان‌گیری
- صدور فاکتور غیررسمی (تکی یا چندکالایی) با سربرگ فروشگاه، تخفیف و مبلغ به حروف
- خروجی متنی، PDF و چاپ برای صفحات اصلی برنامه
- خروجی و ورود کامل داده‌ها در قالب JSON از بخش تنظیمات

## نصب

فایل APK آخرین نسخه از بخش [Releases](https://github.com/specialteam/hesabdari_online_shop/releases/latest) قابل دریافت است. حداقل نسخهٔ اندروید مورد نیاز ۸٫۰ (API 26) است. برای نصب ممکن است لازم باشد نصب از منابع ناشناس برای برنامهٔ مورد استفاده (مرورگر یا مدیر فایل) فعال شود.

## فناوری‌ها

Kotlin، Jetpack Compose (Material 3)، Room، kotlinx.serialization و Navigation Compose.

## ساخت از روی سورس

پیش‌نیازها: JDK 17 و Android SDK با API 35.

```bash
./gradlew testDebugUnitTest assembleDebug
```

### ساختار کد

```
app/src/main/java/ir/hesabdari/shop/
├── data/      # پایگاه داده (Room)، تنظیمات و پشتیبان‌گیری
├── domain/    # محاسبات سود و زیان و فیلترها
├── report/    # ساخت گزارش و خروجی متن و PDF
├── ui/        # صفحه‌ها و مؤلفه‌های Compose
└── util/      # تقویم شمسی و قالب‌بندی اعداد
```

## یکپارچه‌سازی و انتشار

| گردش‌کار | زمان اجرا | خروجی |
| --- | --- | --- |
| `Build` | هر push و pull request | اجرای تست‌ها و APK آزمایشی |
| `Release` | تغییر `version.txt`، push تگ `v*` یا اجرای دستی | APK امضاشده در بخش Releases |

برای انتشار نسخهٔ جدید، شمارهٔ نسخه در `version.txt` تغییر داده و push می‌شود؛ تگ و Release به‌صورت خودکار ایجاد می‌شوند.

### امضای نسخهٔ انتشار

به‌صورت پیش‌فرض APK با کلید موجود در `keystore/release.jks` امضا می‌شود تا نسخه‌های متوالی روی یکدیگر نصب شوند. این کلید در مخزن قرار دارد و برای نصب مستقیم در نظر گرفته شده است. برای انتشار عمومی باید کلید اختصاصی ساخته و از طریق Secretهای مخزن معرفی شود: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS` و `KEY_PASSWORD`.
